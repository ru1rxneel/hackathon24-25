# 🩺 AI-Based Skin Cancer Detection

An AI-powered skin lesion classification system developed as part of a hackathon project. The project uses deep learning and computer vision to analyze skin lesion images and classify them into different categories, providing an accessible AI-assisted approach to preliminary skin lesion analysis.

> **Disclaimer:** This project is intended for educational and research purposes only. It is not a medical diagnostic tool and should not be used as a substitute for professional medical evaluation.

---

## 🚀 Overview

Skin cancer is one of the most common forms of cancer worldwide, and early detection can play an important role in improving treatment outcomes.

This project explores the use of deep learning to automatically analyze images of skin lesions and predict their corresponding class. The system consists of a machine learning pipeline for dataset organization, model training, inference, and an application interface for interacting with the trained model.

The project was developed during a hackathon to explore how artificial intelligence and computer vision can be applied to healthcare-related problems.

## 🧠 Machine Learning Pipeline

The project follows the following workflow:

1. Collect and organize skin lesion image data.
2. Preprocess and prepare the dataset.
3. Split the data into training and evaluation sets.
4. Train a deep learning model using PyTorch.
5. Save the trained model weights.
6. Load the trained model for inference.
7. Process a user-provided skin lesion image.
8. Generate a predicted classification.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ru1rxneel/hackathon24-25.git
cd hackathon24-25
```

Create a virtual environment:

```bash
python -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Application

Run the application using:

```bash
python app.py
```

If the project uses Streamlit, run:

```bash
streamlit run app.py
```
